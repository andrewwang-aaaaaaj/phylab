# 运行与安装说明

## 1. 先确认你要的是哪种安装方式

| 场景 | 推荐方式 | 是否需要华为账号 |
| --- | --- | --- |
| 使用当前这台 Pura 70 Pro+ | 直接安装 `dist/PhyLab-1.0.0-harmonyos7-signed.hap` | 不需要重新登录 |
| 换一台 HarmonyOS 手机 | DevEco Studio 自动签名 + USB 安装 | 需要（免费注册华为开发者账号） |
| 只想看 UI 与交互 | 打开 `design/real-device-preview.png`，或在电脑浏览器打开 `design/preview.html?screen=home` | 不需要 |
| 上架华为应用市场 | 使用 AGC 正式证书与发布 Profile，打 `.app` 后提交审核 | 需要 |

本项目没有服务器依赖。安装完成后，飞行模式下也能使用全部传感器、实验、记录和导出功能。

## 2. 用 DevEco Studio 自动签名（零售手机推荐）

### 2.1 准备

1. 安装 DevEco Studio 26.0.0 或更新版本（支持 API 26）。
2. 注册并登录华为开发者账号。
3. 手机开启开发者模式：
   - 设置 → 关于手机 → 连续点击“版本号”7 次；
   - 设置 → 系统和更新 → 开发人员选项 → 打开“USB 调试”；
   - 连接 USB 后，在手机弹窗选择“允许调试”。
4. 电脑安装华为 USB 驱动（Windows 可用 HiSuite 或 DevEco 自带驱动）。

### 2.2 打开工程

用 DevEco Studio 打开 `PhyLab/` 根目录，等待 Sync 完成。  
如果提示 SDK 不匹配，在 `File → Project Structure → SDK` 中选择 API 26。

### 2.3 自动签名

1. `File → Project Structure → Signing Configs`。
2. 勾选 `Automatically generate signature`。
3. 登录华为账号，等待 DevEco 生成签名材料。
4. 连接手机，点击 `Run 'entry'`。

DevEco 会自动把签名配置写入 `build-profile.json5`，并在 `~/.ohos/config` 下生成 `.p12`、`.cer`、`.p7b`。这些材料与你的华为账号和手机 UDID 绑定，**不要提交到公开仓库**。

### 2.4 命令行安装已签名的 HAP

SDK 自带 `hdc`，路径示例：

```text
<DevEcoStudio>\sdk\default\openharmony\toolchains\hdc.exe
```

```powershell
# 1. 确认设备
hdc list targets

# 2. 安装（-r 覆盖安装）
hdc install -r .\dist\PhyLab-1.0.0-harmonyos7-signed.hap

# 3. 启动
hdc shell aa start -a EntryAbility -b com.phylab.physlab

# 4. 看日志
hdc shell hilog -x | Select-String "PhyLab"
```

如果不想用命令行，DevEco 的 Run 已经包含安装与启动。

### 2.5 AppGallery 上架包

`.hap` 只能用于调试安装；上传应用市场要用 release 签名的 `.app`：

```text
dist/PhyLab-1.0.0-appgallery.app
```

在 AGC 的“版本选取”中点击 **上传新版本**，选择这个 `.app`，不要上传 `.hap`。  
该包已用 release 证书/Profile 签名，`verify-app` 和内部 HAP 校验均通过。

## 3. 使用仓库中的已签名 HAP

`dist/PhyLab-1.0.0-harmonyos7-signed.hap` 已用 **DevEco 自动签名**生成的华为调试证书与 Profile 签名：

- Profile 类型：`debug`
- bundle-name：`com.phylab.physlab`
- Profile 绑定了当前测试机 Pura 70 Pro+ 的 UDID；
- `hap-sign-tool verify-app` 校验通过；
- 该机已实际安装并启动成功。

换机安装时，如果 Profile 中没有新手机的 UDID，会提示 `profile device mismatch` 或 `signature verify failed`。在 DevEco 中重新勾选自动签名即可生成新的 Profile。

安装失败时常见错误：

| 错误 | 含义 | 处理 |
| --- | --- | --- |
| `9568289` / `signature verify failed` | 设备不信任该证书链，或 Profile 不匹配 | 用 DevEco 自动签名重签 |
| `profile device mismatch` | Profile 中没有这台手机的 UDID | 重新生成绑定该设备的调试 Profile |
| `install failed due to grant request permissions failed` | 权限级别/Profile 不匹配 | 用 AGC 调试 Profile，或在 DevEco 中重新签名 |
| `hdc: no devices` | 未连接/未授权 | 检查 USB 调试、驱动、手机弹窗 |
| `The device screen is locked` | 手机锁屏时不允许拉起应用 | 解锁手机后重试 `aa start` |

## 4. 构建

工程已配置为 HarmonyOS 运行时：

```json5
"compatibleSdkVersion": "26.0.0",
"targetSdkVersion": "26.0.0",
"runtimeOS": "HarmonyOS"
```

推荐直接用 DevEco Studio 26.0.0 的内置 HarmonyOS SDK：

1. 打开工程根目录 `PhyLab/`；
2. 等待 Sync；
3. 连接手机并配置自动签名；
4. `Build → Build Hap(s)/APP(s) → Build Hap(s)` 或直接 Run。

不要为本工程手动指定旧版 OpenHarmony SDK 的 `sdk.dir`；否则 DevEco 会提示找不到匹配的 HarmonyOS SDK。

### 4.1 如果需要命令行构建

使用 DevEco Studio 安装目录内的 SDK 与 hvigor，把 `DEVECO_SDK_HOME` 指向 DevEco 的 HarmonyOS SDK，而不是本文档早期的 OpenHarmony 公共 SDK 路径。一般不需要这样做，DevEco 的 Run/Build 已经足够。

产物通常为：

```text
entry/build/default/outputs/default/entry-default-signed.hap
```

### 4.2 重新签名

用 DevEco 自动签名最省事。若你已有 AGC 材料，可使用 SDK 的 `hap-sign-tool.jar`：

```powershell
java -jar <DevEcoStudio>\sdk\default\openharmony\toolchains\lib\hap-sign-tool.jar sign-app `
  -mode localSign `
  -keyAlias "your-key-alias" -keyPwd "***" `
  -appCertFile "your-cert-chain.cer" `
  -profileFile "your-profile.p7b" `
  -inFile "entry-default-unsigned.hap" `
  -signAlg SHA256withECDSA `
  -keystoreFile "your.p12" -keystorePwd "***" `
  -outFile "PhyLab-signed.hap" `
  -compatibleVersion 26 -signCode 1
```

## 5. 首次运行建议

1. 打开应用，底部进入“传感器”，确认哪些传感器显示“可用”。
2. 选“加速度计”，查看实时波形；静止时模长应接近 9.8 m/s²。
3. 进入“实验 → 自由落体”，在厚软垫上方 20–40 cm 释放手机。
4. 结束后回到“记录”页，找到本次实验，点击“导出 CSV”，在系统文件选择器中选择保存位置。
5. 在“记录”页可以开始四通道记录；记录期间保持应用在前台。

## 6. 权限说明

| 权限 | 何时申请 | 拒绝后的表现 |
| --- | --- | --- |
| `ohos.permission.ACCELEROMETER` | 安装时（system_grant） | 加速度相关传感器订阅失败 |
| `ohos.permission.GYROSCOPE` | 安装时（system_grant） | 陀螺仪订阅失败 |
| `ohos.permission.ACTIVITY_MOTION` | 打开计步器时 | 显示“需要用户授权”，可重试 |
| `ohos.permission.READ_HEALTH_DATA` | 打开心率时 | 显示“需要用户授权”，可重试 |

应用不申请 `ohos.permission.INTERNET`，不会联网。

## 7. 卸载与数据

- 卸载应用会删除应用沙箱中的记录。
- 需要保留数据时，先在“记录”页导出 CSV。
- 应用不写入公共相册/下载目录，除非你在系统文件选择器中主动选择。

## 8. 常见问题

**Q：为什么传感器列表里有一些是灰色的？**  
A：系统没有向第三方应用注册该传感器，或者该机型没有这个硬件。应用不会伪造数据。

**Q：为什么心率一直不可用？**  
A：多数华为手机不向三方应用开放后置 PPG；心率通常由系统健康应用或穿戴设备提供。即使 API 存在，设备也可能不注册。

**Q：为什么记录一段时间后没有数据了？**  
A：屏幕熄灭/应用进入后台后，HarmonyOS 可能暂停传感器回调。请保持前台，或后续版本增加前台持续任务。

**Q：CSV 为什么是长表？**  
A：不同传感器采样率不同，长表 `elapsed_ms, sensor, v1…v6` 不会因频率不同而错位，便于用 pandas/Excel 分组分析。
