# 华为手机传感器能力与专业用途调研

> 目标平台：HarmonyOS 7（API 26）  
> 调研对象：通过 `@ohos.sensor` / `@kit.SensorServiceKit` 向第三方应用开放的传感器  
> 说明：不同华为机型、系统版本、地区版本开放的传感器并不相同。本文给出“API 能访问什么”和“这些数据能做什么”，实际可用性必须以应用启动时 `sensor.getSensorListSync()` 的结果为准。

## 1. 结论先行

1. HarmonyOS 的第三方应用不能直接访问传感器驱动，只能访问 Sensor Service 注册的逻辑传感器。`getSensorListSync()` 返回的列表就是这台手机对当前应用开放的全部能力。
2. 华为手机最稳定、最通用的是 **加速度计、陀螺仪、磁力计、重力、旋转矢量、方向、气压计、环境光、接近光、计步器**。这些足以覆盖 phyphox 中大部分力学、振动、转动、姿态、气压与光学实验。
3. **心率 PPG、环境温度、湿度、霍尔、佩戴检测** 等传感器在手机上经常只对系统应用或穿戴设备开放。应用不应假设它们存在，也不应伪造读数。
4. 手机传感器是消费级 MEMS，适合教学、相对比较和趋势观察，不适合替代计量级仪器。采样率、噪声、温漂、安装姿态和系统功耗策略都会影响结果。
5. 仅使用传感器 API 即可做到完全离线：应用不需要 `ohos.permission.INTERNET`，数据在手机内计算、绘图、保存，导出时通过系统文件选择器交给用户。

## 2. HarmonyOS 传感器访问模型

### 2.1 API 入口

```ts
import { sensor } from '@kit.SensorServiceKit';

// 同步获取本机对当前应用开放的传感器
const list: sensor.Sensor[] = sensor.getSensorListSync();

// 订阅：interval 单位是纳秒（ns）
sensor.on(sensor.SensorId.ACCELEROMETER, (data: sensor.AccelerometerResponse) => {
  console.info(`${data.x}, ${data.y}, ${data.z}`);
}, { interval: 20000000 }); // 50 Hz

// 取消订阅
sensor.off(sensor.SensorId.ACCELEROMETER);
```

关键点：

| 项目 | 说明 |
| --- | --- |
| 采样间隔 | `Options.interval`，单位 ns；50 Hz = 20,000,000 ns；200 Hz = 5,000,000 ns。系统会按硬件能力钳制。 |
| 频率档位 | 也可以传 `'game' \| 'ui' \| 'normal'`，分别约 50 Hz、16.7 Hz、5 Hz。 |
| 传感器信息 | `sensor.Sensor` 包含 `sensorName`、`vendorName`、`maxRange`、`minSamplePeriod`、`maxSamplePeriod`、`precision`、`power` 等。 |
| 多设备 | API 19+ 支持 `sensorInfoParam`（`deviceId` / `sensorIndex`），可读取同一账号下其他设备的传感器，本项目未使用。 |
| 权限 | 加速度计、陀螺仪为 `system_grant`（安装时授予）；计步器、心率为 `user_grant`（运行时弹窗）。 |

### 2.2 权限

| 权限 | 类型 | 用途 | 本项目 |
| --- | --- | --- | --- |
| `ohos.permission.ACCELEROMETER` | system_grant | 加速度计、未校准加速度计、线性加速度 | 已声明 |
| `ohos.permission.GYROSCOPE` | system_grant | 陀螺仪、未校准陀螺仪 | 已声明 |
| `ohos.permission.ACTIVITY_MOTION` | user_grant | 计步器、运动识别 | 已声明，按需申请 |
| `ohos.permission.READ_HEALTH_DATA` | user_grant | 心率等健康数据 | 已声明，按需申请 |
| `ohos.permission.MICROPHONE` | user_grant | 声学实验 | 本版本未申请 |
| `ohos.permission.INTERNET` | normal | 联网 | **未申请**，应用完全离线 |

## 3. 传感器清单与专业用途

下表按“运动 / 姿态 / 环境 / 健康 / 高级”分组。`SensorId` 以 HarmonyOS 7 SDK（API 26）为准。

### 3.1 运动

#### 加速度计（ACCELEROMETER = 1）

- 单位：m/s²，三轴
- 权限：`ohos.permission.ACCELEROMETER`
- 专业用途：
  - 自由落体、碰撞、跌落与冲击测量
  - 电梯、汽车、列车的加减速
  - 机械振动与结构振动初筛（配合 FFT 可看主频）
  - 步态、跑步节奏、人体运动强度
  - 手机姿态安装误差与坐标变换教学
- 专业边界：包含重力；量程常见 ±2/4/8 g，强冲击会削顶。做频域分析时要先去除重力/趋势，注意采样率与抗混叠。手机固定方式会改变高频响应。

#### 线性加速度计（LINEAR_ACCELEROMETER = 258）

- 单位：m/s²，三轴
- 专业用途：去重力后的振动、制动、冲击、短时运动积分
- 专业边界：厂商融合结果，滤波参数不公开；严谨频域分析优先用原始加速度计自行去趋势。二次积分求位移会快速漂移。

#### 陀螺仪（GYROSCOPE = 2）

- 单位：rad/s，三轴
- 权限：`ohos.permission.GYROSCOPE`
- 专业用途：
  - 角速度、转速（rpm）、累计转角
  - 转动惯量、摩擦、电机/转盘实验
  - 车辆横摆角速度、机器人差速转向
  - 姿态解算、云台/相机增稳
- 专业边界：零偏随温度漂移，积分角度会累积误差；长期姿态需融合旋转矢量或做零偏校准。

#### 未校准加速度计 / 未校准陀螺仪（281 / 263）

- 单位：m/s² / rad/s，含 biasX/Y/Z
- 专业用途：零偏与噪声分析、六面标定、Allan 方差入门、温漂实验
- 专业边界：原始值未经厂商补偿；需要稳定夹具和已知参考，不适合直接当“更准的传感器”。

### 3.2 姿态

#### 重力（GRAVITY = 257）

- 单位：m/s²，三轴
- 专业用途：电子水平仪、坡度/倾角、静态安装姿态、重力方向教学
- 公式：`θ = acos(gz / |g|)`，双轴坡度可用 `atan2`
- 专业边界：动态加速度会污染结果；运动场景改用旋转矢量。

#### 旋转矢量（ROTATION_VECTOR = 259）

- 单位：无量纲四元数（x, y, z, w）
- 专业用途：三维姿态、AR/VR、头部/关节追踪、云台增稳、四元数教学
- 专业边界：航向受磁干扰；可转欧拉角但存在万向节死锁；长期漂移需要磁力计/视觉修正。

#### 方向（ORIENTATION = 256）

- 单位：度（α 方位、β 俯仰、γ 横滚）
- 专业用途：指南针、俯仰/横滚、太阳能板朝向、摄影构图水平
- 专业边界：欧拉角定义因厂商/版本可能不同；大角度旋转优先记录四元数。

#### 磁力计（MAGNETIC_FIELD = 6）

- 单位：μT，三轴
- 专业用途：地磁场与方位、铁磁材料探测、扬声器/电机漏磁检查、磁罗盘校准
- 公式：`|B| = √(Bx² + By² + Bz²)`；地磁场约 25–65 μT
- 专业边界：手机扬声器、磁吸壳、金属桌面是主要干扰；检测载流导线需要交流磁场，手机采样率和噪声通常不够做精确电流测量。

#### 未校准磁力计（261）

- 专业用途：硬铁/软铁误差建模、磁罗盘标定
- 专业边界：需要多姿态采样与椭球拟合；普通用户用校准后的磁力计即可。

### 3.3 环境

#### 气压计（BAROMETER = 8）

- 单位：hPa
- 专业用途：相对高度、楼层判断、电梯/楼梯垂直速度、天气短时趋势、无人机定高
- 公式：`h = 44330 × [1 − (p / p₀)^0.1903]`
- 专业边界：`p₀` 必须用当地海平面气压或已知海拔标定；温度、风、空调气流会造成漂移。相对高度可到 0.1–1 m 量级，绝对高度误差取决于 `p₀`。

#### 环境光（AMBIENT_LIGHT = 5）

- 单位：lx
- 专业用途：教室/办公室照度、灯具慢速包络、日出日落光强、拍照曝光参考
- 专业边界：消费级光传感器未做余弦修正和光谱匹配，绝对误差可达 ±20%；采样率低，不能直接测 100 Hz 频闪。

#### 接近光（PROXIMITY = 12）

- 单位：cm 或近/远状态
- 专业用途：遮挡/手势检测、口袋识别、自动熄屏逻辑验证、简单占位传感
- 专业边界：多数手机只输出二元状态，量程几厘米；深色物体检测距离更短。

#### 环境温度（AMBIENT_TEMPERATURE = 260）与湿度（HUMIDITY = 13）

- 单位：°C / %RH
- 专业用途：室温/湿度趋势、除湿/加湿对比、温室环境、舒适度记录
- 专业边界：多数华为手机不向三方应用开放独立温湿度传感器；机身发热会严重污染温度读数。只能做趋势，不能替代气象仪器。

### 3.4 健康与交互

#### 计步器（PEDOMETER = 266）

- 单位：累计步数
- 权限：`ohos.permission.ACTIVITY_MOTION`（user_grant）
- 专业用途：步数、步频、活动量、步态实验的时间基准
- 专业边界：系统融合结果，无法获得每一步的精确触地时刻；做步态研究应同时记录加速度原始波形并做峰值检测。

#### 心率（HEART_RATE = 278）

- 单位：bpm
- 权限：`ohos.permission.READ_HEALTH_DATA`（user_grant）
- 专业用途：静息心率、运动后恢复、呼吸训练、生理信号教学
- 专业边界：多数华为手机不向三方应用直接开放后置 PPG；只有平均 bpm，没有逐拍 R-R，无法可靠计算 HRV。不能用于医疗诊断。

#### 霍尔（HALL = 10）

- 单位：开关量/状态
- 专业用途：磁吸保护壳、翻盖开合计数、磁铁位置检测
- 专业边界：阈值触发，不是线性磁场计；部分机型不开放。

#### 佩戴检测（WEAR_DETECTION = 280）

- 单位：开关量
- 专业用途：佩戴状态、省电策略验证
- 专业边界：主要是手表/手环能力，手机通常不可用。

### 3.5 其他 API 中存在但本项目未单独建卡的传感器

| SensorId | 名称 | 说明 |
| --- | --- | --- |
| `PEDOMETER_DETECTION = 265` | 计步检测 | 单次脚步事件，适合做步频 |
| `SIGNIFICANT_MOTION = 264` | 显著运动 | 低功耗唤醒，不适合连续波形 |
| `FUSION_PRESSURE = 283` | 融合气压 | API 22+，主要面向手表 |
| `MAGNETIC_FIELD_UNCALIBRATED = 261` | 未校准磁场 | 标定与误差分析 |

## 4. 华为手机的实际开放情况

### 4.1 典型可用组合

以近几代华为直板旗舰（包括 Pura 系列）为例，第三方应用通常能拿到：

- 加速度计、陀螺仪、磁力计
- 重力、线性加速度、旋转矢量、方向（系统融合）
- 气压计（多数旗舰配备）
- 环境光、接近光
- 计步器（需运动权限）
- 霍尔（部分机型）
- 未校准加速度/陀螺（部分机型）

经常不可用或受限制：

- 心率 PPG（系统健康应用/穿戴设备优先）
- 环境温度、湿度（多数手机没有独立器件，或只对系统开放）
- 佩戴检测（手机没有该场景）
- 融合气压（手表能力）

> 本项目在运行时读取真实传感器列表，不假设 Pura 70 Pro+ 一定具备某一项。应用内灰显“不支持”即为系统未注册，不是应用故障。

### 4.2 为什么不能“绕过系统”读传感器

HarmonyOS 的传感器服务位于系统进程，应用通过 IPC 调用。没有注册到 Sensor Service 的传感器，第三方应用无法通过其他 API 直接读驱动；这是隐私与功耗设计的一部分。应用应尊重系统能力边界，而不是用伪造数据填充界面。

### 4.3 采样与后台限制

- 高频采样（100–200 Hz）会显著增加功耗，建议实验时保持前台、缩短单次时长。
- 屏幕熄灭或应用进入后台后，系统可能暂停传感器回调；长时记录需要前台服务/持续任务能力，本项目未申请后台持续任务，以避免额外权限与通知复杂度。
- 不同机型会对 `interval` 做钳制；应用应以实际时间戳计算频率，而不是假设 50 Hz 一定准确。

## 5. 与 phyphox 的对照

phyphox 的核心不是“传感器列表”，而是“把传感器变成可解释的实验”。本项目参考其产品结构，实现了其中可在 HarmonyOS 上离线完成的部分。

| 能力 | phyphox | 本项目 PhyLab | 说明 |
| --- | --- | --- | --- |
| 原始传感器读数 | ✅ | ✅ | 18 类传感器卡片，实时三轴/单值 |
| 实时曲线 | ✅ | ✅ | Canvas 多序列波形，160–180 点窗口 |
| 多传感器记录 | ✅ | ✅ | 四通道快速记录 + 单传感器记录 |
| CSV 导出 | ✅ | ✅ | 长表格式，系统文件选择器保存 |
| 预设实验 | ✅ 大量 | ✅ 6 个 | 自由落体、单摆、转动、磁场、气压高度、水平仪 |
| 自定义实验编辑器 | ✅ | ❌ | 需要可视化实验描述语言与运行时解释器 |
| 远程控制（浏览器） | ✅ | ❌ | 与“完全离线、无服务器”目标冲突 |
| 声学/麦克风实验 | ✅ | ❌ | 需要麦克风权限、音频采集与低延迟处理，本版本未纳入 |
| GPS/GNSS 实验 | ✅ | ❌ | 需要定位权限与室外测试，本版本未纳入 |
| 传感器融合/FFT | 部分 | ❌ | 当前提供时域统计与过零检测，未做 FFT |

### 已实现的 6 个实验

1. **自由落体**：检测失重区间与冲击峰值，`h ≈ ½gt²`，反推下落高度。
2. **单摆与振动**：对 `|a| − g` 做过零检测，提取周期 `T` 与频率 `f`。
3. **转动实验室**：陀螺仪 Z 轴角速度 → rpm，积分得到累计转角。
4. **磁场探针**：总场强、相对基线偏移、峰值偏移，判断铁磁/强磁体。
5. **气压高度计**：以起始气压为 `p₀`，计算相对高度与垂直速度。
6. **电子水平仪**：重力矢量 → 总倾角、X/Y 双轴坡度。

## 6. 更专业的实验设计建议

### 6.1 力学

- **自由落体**：用软垫接住手机，采样 200 Hz；用失重持续时间算高度，用冲击峰值算平均冲击加速度。多次测量取平均，讨论空气阻力与软垫缓冲。
- **单摆**：手机固定在摆杆末端，摆角 <15°；用过零间隔求周期，改变摆长验证 `T = 2π√(L/g)`。
- **弹簧振子**：手机固定在滑块上，沿运动方向采集加速度；观察阻尼衰减与频率漂移。
- **转动**：手机固定在转盘上，Z 轴对准转轴；比较不同半径/质量下的角速度与转速，讨论转动惯量。
- **振动频谱**：需要 FFT。可把 200 Hz 采样数据导出后用 Python/Origin 分析，识别电机、风扇、结构的共振峰。

### 6.2 姿态与导航

- **电子水平仪**：静态测量桌面、墙面、太阳能板倾角；旋转 90° 检查双轴正交性。
- **姿态融合**：同时记录陀螺仪与旋转矢量，比较积分角与融合角，观察漂移。
- **磁罗盘**：远离磁吸壳，做 8 字校准；比较室内外航向误差。
- **电梯/楼层**：气压计 + 加速度计联合判断电梯启停与楼层变化。

### 6.3 环境

- **气压高度**：从 1 楼到高层，记录相对高度；用已知楼层高度反算 `p₀`，讨论天气变化的影响。
- **照度比较**：同一时间段比较室内、走廊、窗边、户外的照度；避免手机自动亮度调节影响（传感器读数不受屏幕亮度影响，但机身姿态会遮挡）。
- **温湿度**：如果设备支持，静置 5 分钟后再记录，避免手握和充电发热；与标准温湿度计对比做偏差修正。

### 6.4 健康与交互

- **步频**：计步器给累计步数，加速度计给原始步态波形；用峰值检测计算步频与左右脚对称性。
- **心率趋势**：静息、运动后恢复；注意 PPG 受运动伪影影响，不能用于诊断。
- **翻盖/磁吸**：霍尔传感器做开合计数；用磁铁靠近/远离观察阈值。

## 7. 能力边界与安全

- 手机不是计量仪器：MEMS 加速度计噪声、零偏、温漂、量程都有限；磁力计受手机内部磁体干扰；气压计受天气与空调影响。
- 光学/PPG 传感器受肤色、佩戴、环境光影响；本项目不提供医疗建议。
- 自由落体/转动实验必须使用软垫、护套和牢固夹具，避免摔机或甩出。
- 强磁体可能影响手机指南针、磁传感器和心脏起搏器等医疗设备，避免长时间紧贴。
- 数据默认保存在应用沙箱；导出由系统文件选择器完成，应用不申请网络权限。

## 9. Pura 70 Pro+ 实测补充（2026-10-24）

测试机：HUAWEI Pura 70 Pro+（HBN-AL80），HarmonyOS 7.0.0.109，API 26。
