## 7. 真机测试中发现并修复的问题

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 传感器页显示 `22 / 18 可用` | 系统传感器列表包含重复/虚拟项 | 按目录去重统计，改为 `13 / 18` |
| “电磁”分类不显示 | 分类数组漏了 `电磁` | 补入分类数组 |
| 详情页一直 `0.00` | `Index.onPageHide()` 在详情页订阅后停掉了同一传感器 | 路由跳转前停止预览，移除 `onPageHide` 的停止逻辑 |
| 实验样本数极小、CSV 为空 | `onSample()` 未写入 `Recorder` | 增加 `recorder.add()` |
| 状态栏图标几乎不可见 | 系统栏内容色为浅蓝 | 改为深色 `#1D1D1F` |
| 导出按钮无响应 | `Text.onClick` 在真机点击链上不稳定 | 改为原生 `Button`，修正点击坐标 |
| 占位符显示为粗黑横条 | `—` 在真机字体中的字形 | 改为 `待测` / `暂无`，占位字号缩小 |

## 9. 已知限制

- 气压计、心率、体温、湿度等传感器是否开放由机型/系统权限决定；本机气压计不可用。
- 后台/锁屏会暂停传感器回调；记录时需保持应用前台。
- `dist` 中的 HAP 是绑定本机 UDID 的 debug 签名；换机需重签。`dist` 中的 `.app` 是 release 签名，供 AppGallery 上传；公开上架还需通过 AGC 审核与备案/资质要求。
- 未做长时间功耗、发热和 3 分钟以上连续记录测试。
